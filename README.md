# Hackathons

One folder for everything from hackathons: each event gets its own subfolder with its plan, notes and links to the code repo.

| Folder | Event / project | Code |
|---|---|---|
| [clustering-busters](clustering-busters/PLAN.md) | Clustering Busters: scam checker in plain Czech | [cinconko/clusterbusters](https://github.com/cinconko/clusterbusters) (local clone: `../clusterbusters`) |

## Conventions

- Each project folder has a `PLAN.md` (goal, scope, timeline, demo script) and a `NOTES.md` for running notes.
- Code stays in its own git repo; this folder holds planning and writing only.
